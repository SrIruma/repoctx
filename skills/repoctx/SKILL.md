# repoctx

repoctx keeps AI coding-agent context files (AGENTS.md, CLAUDE.md, .cursorrules) truthful by regenerating the code-derived sections from the real repository and detecting rot.

## When to use

- The user asks to update or refresh AGENTS.md / CLAUDE.md / .cursorrules.
- A context file looks out of date (commands, paths, modules).
- Before finishing a task that changed commands, scripts, dependencies, manifests or package layout.
- In CI, to gate merges on context drift.

## When NOT to use

- Editing human-written sections (overview, conventions, TODOs) — those are owned by people.
- Repositories with no manifest (repoctx has nothing to extract).

## Core workflow

1. `repoctx info [dir]` — see what was detected (manifests, commands, modules).
2. `repoctx init [dir]` — bootstrap a context file where none exists.
3. `repoctx generate [dir]` — regenerate the code-derived tables (preserves human content).
4. `repoctx audit [dir] --check` — fail if the context drifted.

## Rules

- Never hand-edit the tables between `<!-- repoctx:start -->` and `<!-- repoctx:end -->`.
- Run `repoctx generate .` after changing commands, scripts, dependencies or manifests.
- Run `repoctx audit . --check` before finishing; fix anything it reports.
- Prefer `--file` to target a specific context file; otherwise repoctx discovers all AGENTS.md/CLAUDE.md in the tree.

## Output format

When you report an audit result, use this shape:

```markdown
## Context health

**File:** AGENTS.md · **Score:** <score>/100

| Check | Result |
|---|---|
| commands | 11 claimed, all found |
| paths | 9 referenced, 1 stale |

### What to fix
- `docs/api.md` — referenced in the context file, but the file moved.

### How to fix
- update the path, or run `repoctx generate .` if the command list changed
```

- Quote the exact path or command the audit reported. Never paraphrase it.
- If every check passes, say so in one line and stop. Do not invent findings.

## Troubleshooting

- `no context files found`: the repo has no AGENTS.md/CLAUDE.md; run `repoctx init`.
- `audit` reports stale paths: the referenced file moved or was renamed; update or remove the reference.
- `audit` reports ghost commands: a claimed command no longer exists in any manifest; remove it.
- Markers missing: `generate` refuses to overwrite a file without markers; add `<!-- repoctx:start -->` / `<!-- repoctx:end -->` or use `init`.

## Repo Context Maintenance

The Commands and Modules tables between `<!-- repoctx:start -->` and
`<!-- repoctx:end -->` in `AGENTS.md` are generated by repoctx from the code —
never hand-edit them.

After you change commands, scripts, dependencies, manifests, or move packages, run:
1. `repoctx generate .`  — regenerate the code-derived tables
2. `repoctx audit . --check`  — fail if the context drifted

Fix anything `repoctx audit` reports before finishing the task.
